\# CampusFind 🎓



\*\*A Campus Lost and Found Application\*\*



CampusFind is an Android application designed to help college students report, browse and recover lost or found belongings within their campus.



The application provides a simple platform where students can share item information and check whether reported items have been resolved.



\## ✨ Features



\- \*\*Report Lost Items:\*\* Report belongings that have been lost on campus.

\- \*\*Report Found Items:\*\* Share details of items found on campus.

\- \*\*Browse Items:\*\* Explore reported lost and found items.

\- \*\*Search Items:\*\* Search for items by name, location or description.

\- \*\*Item Details:\*\* View detailed information about reported items.

\- \*\*Resolved Reports:\*\* Separate resolved reports from active reports.

\- \*\*Student Profile:\*\* View and manage student profile information.

\- \*\*Contact Information:\*\* View available reporter information.

\## ⚙️ Installation and Setup



1\. Clone this repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/Raviraj301006/CampusFind.git

&#x20;  ```



2\. Open Android Studio.

3\. Select \*\*Open\*\* and choose the cloned CampusFind project folder.

4\. Allow Gradle synchronization to complete.

5\. Run the application using an Android emulator or physical Android device.
