# CampusFind 🎓

### A Campus Lost and Found Application

CampusFind is an Android application developed to help college students report, browse and recover lost or found belongings within their campus.

The application provides a simple platform where students can share item information and check whether reported items have been resolved.

## ✨ Features

- 🔍 Report Lost Items
- 🎒 Report Found Items
- 📋 Browse Reported Items
- 🔎 Search Items by Name, Location or Description
- 📱 View Detailed Item Information
- ✅ Manage Active and Resolved Reports
- 👤 Student Profile Management
- 📞 View Available Contact Information

## 🛠️ Technologies Used

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Raviraj301006/CampusFind.git
   ```

2. Open Android Studio.
3. Select **Open** and choose the CampusFind project folder.
4. Allow Gradle synchronization to complete.
5. Run the application on an Android emulator or physical Android device.

## 💾 Data Storage

The application currently uses Android SharedPreferences and JSON for local data storage.

Student profile information and item reports are stored locally on the device.
